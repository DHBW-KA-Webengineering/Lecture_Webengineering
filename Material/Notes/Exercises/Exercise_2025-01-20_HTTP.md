# Übungsaufgabe HTML

Im Rahmen dieser Übung arbeiten Sie an der Entwicklung einer webbasierten Anwendung zur Erfassung, Speicherung und Auswertung
von Arbeitszeiten – eine sogenannte digitale "Stechuhr".
